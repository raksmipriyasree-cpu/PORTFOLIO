DATA / DASHBOARD / FA-2

LogiSight Delivery Intelligence.

An interactive last-mile delivery analytics dashboard built to move from data to insight, then from insight to a practical stakeholder decision.

Open project README →
DATASET

43,739 records

The dashboard works with approximately 43,739 delivery records across 16 fields.

CORE ANALYSES

5 compulsory + 3 extra

Delay, vehicle, agent, area and category analyses are joined by time-of-day, distance and pickup-efficiency views.

WORKFLOW

Data → Decision

Cleaning, transformation, metrics, visualisation, interaction, insight, risk and action form one continuous flow.

INSIGHTS

What the dashboard is designed to reveal.

These are the decision-oriented questions behind the interface, rather than charts presented for their own sake.

01

Delay drivers

Compare delivery time against weather and traffic to identify conditions associated with slower performance.

02

Vehicle performance

Compare average delivery performance across vehicle types to support operational planning.

03

Agent performance

Explore relationships between agent rating, agent age and delivery time without reducing performance to a single number.

04

Area & category patterns

Identify areas with higher average delivery times and categories with different delivery-time distributions.

05

Pickup efficiency

Longer pickup durations are associated with higher delivery times, pointing to pickup efficiency as an operational lever.

06

Distance & time

Examine whether longer delivery distances correspond with longer delivery times and use the result in operational interpretation.

MANAGER NOTE

Use the dashboard to ask better operational questions.

The manager view is intentionally filter-first: select weather, traffic, vehicle, category, area or order date, then watch the KPIs and visual analyses update.

The value is not the chart alone. It is the ability to move from “what changed?” to “where should we investigate next?” while keeping the selected segment visible.

DECISION LENS

What should change?

Use delay patterns to investigate bottlenecks, compare vehicles before operational changes, examine area/category performance and review pickup efficiency before treating delivery time as a single isolated metric.

INVESTOR NOTE

A scalable analytics pattern.

The strongest product idea here is not one specific chart. It is the reusable path from messy operational data to a decision interface: clean → derive → filter → analyse → explain.

Future extensions can add forecasting, anomaly detection, live weather and traffic, geographic mapping, automated alerts and role-based dashboards.

PRODUCT THINKING

From assessment to something with a wider use case.

LogiSight demonstrates how an academic dashboard can be framed as a practical analytics product: a manager-facing interface, a repeatable data pipeline and a clear route from insight to action.

STORYBOARD → WORKING SYSTEM
